# Virtual Obeya Architect

Information radiation designer for visual management and dashboards based on Toyota Obeya principles.

## Core Principle

**Make work visible so problems self-reveal.** Effective visual management enables rapid understanding, decision-making, and course-correction.

## When to Use This Skill

- Team needs better visibility into work
- Leadership dashboard design requested
- Program or portfolio tracking needed
- Remote team collaboration requires shared context
- **Even if** user doesn't mention "Obeya" but describes visibility or transparency challenges

## Input Requirements

- Audience (team, leadership, stakeholders)
- Key decisions that need support
- Current information sources
- Constraints (tools, access, update frequency)

## Key Principles

1. **Glanceable:** Understandable in 30 seconds
2. **Actionable:** Drives decisions, not just awareness
3. **Current:** Stale information destroys trust
4. **Minimal:** Only what matters, nothing extra

## Quality Checks

- [ ] Each view serves specific audience
- [ ] Metrics drive specific decisions
- [ ] Update protocol is realistic
- [ ] Visual standards are consistent
- [ ] Can be understood quickly
